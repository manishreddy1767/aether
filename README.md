# AETHER

AETHER is a privacy-focused Windows desktop browser with local AI-powered research tools.

## Vision

- Minimal, customizable browsing experience
- Local AI assistance for webpage research
- Privacy and security by design
- Research tools with traceable sources

## Planned Technology

- Electron
- JavaScript, HTML, and CSS
- Ollama with a local language model
- Git and GitHub

## Development Status

Early development — project setup and planning.

## Principles

- Browsing should work without AI.
- AI features should run locally where practical.
- Webpage content is untrusted input.
- Security, privacy, and accessibility are core requirements.
